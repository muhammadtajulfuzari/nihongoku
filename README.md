# NihongoKu

Aplikasi pembelajaran bahasa Jepang berbasis web dan Android
untuk calon pekerja ke Jepang.

Demo web: https://muhammadtajulfuzari.github.io/nihongoku/

## Fitur
- Belajar Hiragana, Katakana, Kanji, dan Kosakata
- Kuis dengan sistem XP dan streak (gamifikasi)
- Profil dan progres belajar
- Mode gelap
- Tersedia sebagai aplikasi Android (Capacitor)

## Teknologi
HTML, CSS, JavaScript, Capacitor, Android Studio

## Cara menjalankan
### Web
Buka index.html di browser, atau kunjungi tautan demo.

### Android
npm install
cp index.html script.js style.css www/
npx cap sync android
npx cap open android
Lalu klik Run di Android Studio.
